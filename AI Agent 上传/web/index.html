帮助

写作

生成团课总结、团课推文、活动报告、会议总结、自我介绍、PPT 演讲稿，或对已有文字进行润色。

  • 点顶部快捷指令，补上具体活动信息即可生成。
  • 粘贴已有内容后可说"润色"、"改写成公文风格"。

翻译

翻译小说文本，或批量导入 TXT / EPUB / MOBI 文档翻译。

  • 直接粘贴文本，或点"批量导入文档"一次选择多个文件。
  • 队列最多同时翻译 2 个文档，全部完成后可逐个复制/下载。
  • 选择源语言、目标语言与风格；术语表可固定人名地名译法。

章节

批量导入书籍文件，按规则拆分章节、编辑后导出为电子书。

  • 支持 TXT / EPUB / MOBI，一次可导入多个文件，点文件切换编辑。
  • 拆分规则：中文章节、英文章节、卷、序言附录、自定义正则、按长度均分。
  • 可改标题、预览、删除章节；导出带目录的 EPUB / TXT / MOBI。

文本工具

合并 TXT、网页转 TXT、批量转 PDF，全部支持批量处理。

  • 合并 TXT：多选文件，或选文件夹自动按名称顺序合并其中全部 TXT 为一个文件。
  • 网页转 TXT：选择 HTM/HTML 文件或整个文件夹，逐个转为纯文本。
  • 批量转 PDF：选择 TXT 文件或文件夹，由本机 Word 生成 PDF，逐项下载。

设置

配置 DeepSeek API Key、选择模型与温度参数。

  • 首次使用：点"设置"，粘贴 API Key，保存后点"测试连接"验证。
  • deepseek-chat 快速实惠；deepseek-reasoner 更强但更慢。
  • API Key 仅保存在本机 config.json，不会上传。
